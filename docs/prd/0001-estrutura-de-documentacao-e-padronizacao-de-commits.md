# PRD-0001. Estrutura de documentação e padronização de commits

- **Data:** 2026-08-25
- **Estado:** Implementado

## Objetivo

Estabelecer a base de documentação e o rastreio de mudanças do projeto.

## Requisitos

- Estrutura de documentação mínima com AGENTS.md como ponto de entrada.
- Registros de decisão de arquitetura (ADRs).
- Mensagens de commit rastreadas por PRD.
- Validação local por hook nativo do Git.

## Critérios de aceite

- Documentos criados.
- Hook documentado em CONTRIBUTING.md.
- Hook rejeita commits fora do padrão.
